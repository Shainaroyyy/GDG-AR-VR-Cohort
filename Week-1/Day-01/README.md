# Day 01, Monday 9th November&#x20;

Welcome to Day 01 of the GDG AR/VR Cohort!

In our first session, we explored the Blender interface, learned basic viewport navigation and got familiar with the fundamental tools used to interact with 3D objects.

## 1. Topics Covered

### Opening and Navigating Blender

- Opening a Blender project.
- Scrolling to zoom in and out.
- Understanding the 3D viewport.
- Understanding the axes (X, Y and Z).
- Moving around the viewport and changing the viewing angle.

### Understanding Modes

Blender has different modes that allow us to interact with objects in different ways.

**Object Mode**

- Used to select, move and manipulate entire objects.
- `G` — Grab / Move

**Edit Mode**

- Used to modify the geometry of an object.
- Three selection types:
  - Vertex Selection
  - Edge Selection
  - Face Selection

### Basic Transformation and Modelling Shortcuts

| Shortcut | Function    |
| -------- | ----------- |
| `G`      | Grab / Move |
| `S`      | Scale       |
| `R`      | Rotate      |
| `E`      | Extrude     |

These shortcuts form the foundation of working with objects and creating 3D models in Blender.
