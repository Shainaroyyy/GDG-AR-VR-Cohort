# Blender Installation Guide

Welcome to the GDG On Campus IGDTUW AR/VR Cohort!

Before our first class, please make sure Blender is downloaded and installed on your system. Follow the instructions for your respective operating system below.

## 1. Official Blender Website

**Website:** https://www.blender.org/

**Download page:** https://www.blender.org/download/

Blender is free and open-source. Always download it from the official website.

## 2. Windows Installation

**Download Blender for Windows:**  
https://www.blender.org/download/

### Steps

1. Open the official Blender download page.
2. Select the Windows installer.
3. Once downloaded, open the `.msi` installer file.
4. Follow the installation wizard and accept the default settings.
5. Once installation is complete, launch Blender.

🎥 **YouTube Tutorial:** [Blender Installation Guide for Windows](hhttps://youtu.be/gKAcnpNYIA0?si=HrBKEKl-NlbG4z4c)

## 3. macOS Installation

**Download Blender for macOS:**  
https://www.blender.org/download/

### Steps

1. Open the official Blender download page.
2. Select the macOS version.
3. Choose the correct version for your processor:
   - **Apple Silicon:** M1, M2, M3, M4 and newer Apple Silicon Macs.
   - **Intel:** Intel-based Macs.
4. Download the `.dmg` file.
5. Open the downloaded file and drag Blender into your Applications folder.
6. Launch Blender from Applications.

*Note: If macOS displays a security prompt when opening Blender for the first time, follow the system instructions to allow the application to open.*

🎥 **YouTube Tutorial:** [Blender Installation Guide for macOS](https://youtu.be/xdSjK4r5TWg?si=sTXuqggVb_M3GP0m)

## 4. Verify Your Installation

After installation:

- Open Blender.
- Wait for the default startup scene to load.
- You should see a 3D viewport with a cube, camera and light.

If you can see the default scene, your installation is successful!

## 5. Need Help?

If you face any installation issues, don't worry. Note down the error or take a screenshot, and we will troubleshoot it during our class on 9th November.

**Please complete the installation before our first class so we can focus on learning and exploring Blender together.**
